## What it does

`main.ts` writes a single line — the one-line pitch for the worst pizza topping imaginable — to `/output/entry.txt`. The program is fully deterministic: no
randomness, no network, no input. It always writes exactly the same line.

> Warm mayonnaise, gummy bears, and a crust that sighs when you bite it. This is not a pizza. It is a cry for help that someone melted cheese on.

## Run

Requires Node 22.18 or later (the grader runs Node 22.23.4):

```sh
node main.ts
cat /output/entry.txt
```
